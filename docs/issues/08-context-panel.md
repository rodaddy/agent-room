## Goal
Build the context panel for code snippets, files, and attached references.

## Deliverables
- side panel UI for context items
- support for pasted code blocks and lightweight file attachments
- room messages can reference attached context entries
- truncation and expansion UX for long code snippets

## Acceptance criteria
- user can attach context before sending a message
- agents receive structured context metadata
- room timeline can show which context entries were used
- code snippets remain readable on desktop screens

## Notes for Codex
Start with local uploads or text snippets. Keep repo browsing out of MVP unless it falls out naturally.
